Lista 2 - Flutter

Projeto referente aos exercícios de fixação sobre manipulação de listas, exibição dinâmica de dados e componentes visuais como ListView.builder, Card e ListTile.

Estrutura das pastas:
exercicio01: Lista de jogos usando ListView.builder e ListTile.
exercicio02: Catálogo de veículos usando a classe Veiculo exibida em Cards.
exercicio03: Lista de alunos com notas utilizando a classe Aluno.
exercicio04: Cadastro dinâmico de jogos favoritos com suporte para remover itens.
exercicio05: Cadastro de periféricos com validação e gerenciamento de estado.
